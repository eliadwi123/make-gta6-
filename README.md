**Port Marisol** — an original 3D open-world crime game for the web, built for make.fun's "Make GTA 6" bounty. Explore a fictional coastal city on foot or by car, follow a four-mission story with Rio & Maya, steal cars, and outrun a 1–5 star police wanted system. Pure three.js, fully offline, no build step.

## Run it

```sh
git clone https://github.com/eliadwi123/make-gta6-.git
cd make-gta6-
node serve.ts
```

Then open http://localhost:8080 in your browser.
